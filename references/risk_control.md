# 风控规则总览

本 skill 严格遵守双重风控规则。

## 1. 小红书侧（采集）
- **API 调用间隔 ≥1 秒**：任意两次 MCP tools/call 之间必须 sleep ≥1s
- **笔记间间隔 ≥30 秒**：连续采集多篇笔记时，笔记之间 sleep ≥30s
- **评论采集节流**：`scroll_speed=slow`，`limit=20`（每笔记最多 20 条一级评论）
- **不点二级回复**：`click_more_replies=false`，避免额外请求
- **风控信号立即停止**：响应里出现"风控/异常/blocked/forbidden/请稍后再试"等关键词，立即停止并报警
- **登录态独占**：小红书同账号不允许网页多端登录，登录 MCP 后浏览器网页端会被踢

## 2. 飞书侧（写入）
- **API 调用间隔 ≥1 秒**：任意两次 lark-cli 命令之间必须 sleep ≥1s
- **批量上限**：单批 record 操作 ≤200 条，遇到 `1254291` 串行重试
- **附件上传**：`--file` 必须是相对路径

## 3. 实现要点
- Python 脚本里用 `time.sleep(1.0)` 隔开每次 `subprocess.run(lark-cli ...)`
- bash 多次 curl 调用 MCP 时用 `sleep 1` 隔开
- 笔记循环里 `time.sleep(30.0)` 隔开
- 任何 `RuntimeError("风控信号")` 抛出后，主流程立即退出，不继续后续采集

## 4. 批量场景注意
未来若要批量采集多个账号 × 多天的笔记：
- **不要同 IP 多账号串采**（最高风险）
- 每个账号之间间隔 ≥10 分钟
- 每 5 篇笔记休息 10-30 分钟
- 强烈建议使用小号而非主号
